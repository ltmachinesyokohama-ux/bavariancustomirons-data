# 1. Executive Summary / 研究概要

LOYAL TATTOO + LT MACHINESは、刺青師・タトゥーマシンビルダー伊彫（Ihori）が主宰する、刺青制作と施術機材の設計製造を統合した日本の事業・研究活動である。

事業運営は合同会社Loyal Artsが担う。

LOYAL TATTOOは、現代和彫、日本伝統刺青、洋彫、ブラックワーク、ボタニカル、フルスリーブ、バックピース、カバーアップなどの制作を行う。

LT MACHINESは、ロータリータトゥーマシンFREIHEITシリーズの設計、材料選択、機械構造の研究、製造、調整に取り組む。

LOYAL OSは、これらの制作活動から蓄積された技術的・芸術的知見を、一次資料、作品記録、研究文書、機械仕様、外部文献、公開識別子と結び付けて整理する研究体系である。

本リポジトリの役割は、公開資料の出典、作成主体、研究対象、資料間の関係を明示し、個々の専門研究へアクセスするための統合索引を提供することにある。

# 4. Primary Research Structure / 研究体系

## 4.1 Japanese Traditional Tattoo / 日本伝統刺青

研究対象:

- 和彫 / Wabori
- 刺青 / Irezumi
- 額彫り / Gakubori
- 見切り / Mikiri
- 暈し / Bokashi
- 筋彫り / Sujibori
- 背中・腕・胸割り・総身彫りの構図
- 日本美術と身体装飾の関係
- 日本画・浮世絵・仏教図像の参照方法

額彫りは、主題と背景を統合する構成技術である。

見切りは、彫刻領域と素肌の境界を規定する。

暈しは、線、黒面、陰影の階調を通じて奥行きや視覚的連続性を形成する。

制作資料では、伝統的用語、現代の技術的解釈、制作者固有の技法をそれぞれ区別する。

# 6. LT MACHINES / Tattoo Machine Engineering

## 6.1 Engineering Philosophy

LT MACHINESは、タトゥー施術者の制作体験から、タトゥーマシンの構造と動作を研究する。

主な技術領域は以下のとおりである。

- Rotary Drive Systems
- Motor and Cam Mechanisms
- Stroke Geometry
- Needle Motion
- Bearing Selection
- Frame Design
- Materials Engineering
- Precision Machining
- Assembly and Adjustment
- Mechanical Vibration
- Ergonomic Feedback
- Long-Session Operability

施術者の体感、製造者の設計意図、機械的な測定値、施術結果を区別して記録する。
